# First Antigravity prompt

Paste the following into a new conversation after opening the project root.

```text
Read AGENTS.md, .agents/rules/project-memory.md,
.agents/rules/plan-before-build.md, memory/decisions.md,
docs/OPEN-DECISIONS.md, BUILD-PLAN.md and
plans/P00-workspace-bootstrap.md.

This is the Oderinde Stephen Client Portal. Stephen is the approver.
We are starting from scratch on Windows with Antigravity 2.24.0.
The current release has Owner and Client roles only, all 18 client
screens, English, desktop/tablet/mobile, and dark/light themes.

First inspect the workspace and available tool versions without
printing secret values. Explain which files exist and which are
only planned. Do not create another framework or authentication
provider. Do not create external accounts, buy services, publish,
or run production migrations.

Prepare P00 as a concrete, reviewable plan, including exact
scaffolding commands, versions to be pinned, script names,
affected files, acceptance checks and real objections.
Propose the unresolved supporting tools clearly. Do not label a
proposal as Stephen's approved decision.

Group only blockers relevant to the next task into one concise
question list. Hosting, payments and ambiguous messaging answers
are already recorded; do not invent their missing details or
repeat settled questions. Unrelated pending decisions do not block
independent work that Stephen has approved.

Show the plan path, readiness verdict and objections. Ask for
approval only when the plan is concrete. Do not write application
code before Stephen approves that task plan. Once approved,
complete its scope, verify it and keep the execution log current.
```
