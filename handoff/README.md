# Handoff notes

Use this directory for self-contained operating instructions, external integration notes and the final Owner guide. It is not evidence that a service has been implemented.

For each integrated provider, record its account owner, intended capability, verified API/SDK generation, environment, callback setup, permission boundary, retry/idempotency behavior and actual verification result. Include variable names, never secret values.

Label interfaces CONFIRMED, PROPOSED or OPEN. Do not give an unselected provider a fictional endpoint contract. If a preview uses fixtures, say so. The reviewer should be able to understand the remaining decision without reading internal agent memory.

Before final handoff, cover Owner setup/recovery, Client activation, project assignment, Drive permissions, file review and restoration, invoices, Cal.com reconciliation, push preferences, support handling, deployment and recovery. Include known limits and tested behavior. Only Stephen confirms completion.
