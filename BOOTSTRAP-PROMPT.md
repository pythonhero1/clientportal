# Recover a missing workflow

The normal starting prompt is START-PROMPT.md. Use this only if parts of the workflow were lost.

```text
Inspect the current workspace and Git history before rebuilding
missing agent documents. Preserve application source and existing
decisions. Stephen is the approver; the current release has Owner
and Client only, all 18 client screens, English, both themes and
desktop/tablet/mobile support.

Restore the project-specific root protocol, concise rules, project
skills, memory families and 14-section task plan template from the
latest reviewed version if available. Do not generate a generic
stack, seed fictional corrections or change existing policies.

Read BUILD-PLAN.md, docs/DECISION-REGISTER.md and
docs/OPEN-DECISIONS.md. Recover what is actually established.
If an authoritative file is missing, mark that fact and group the
specific recovery questions. Never use a guessed policy to replace
missing history. Use Git to make the restored change reviewable.
```
